Энэ мини–судалгаанд **Transfer Function**–ийн математик суурь болон инженерийн ач холбогдлыг тайлбарлав.  
Цагийн домэйны LTI (linear time-invariant) дифференциал тэгшитгэлийг Лапласын хувиргалтаар s-домэйны  
алгебрын илэрхийлэл болгон хувиргаж,  
оролт–гаралтын хамаарлыг **G(s) = Y(s) / X(s)** хэлбэрээр илэрхийлэх зарчмыг төвд нь байрлуулсан.  

Transfer Function ашигласнаар системийн туйл, нүх, тогтвортой байдал, түр ба тогтмол төлөвийн хариу,  
мөн closed-loop system шинжилгээ болон удирдлагын зохиомжийг системтэйгээр үнэлэх боломжийг үүсгэнэ.
